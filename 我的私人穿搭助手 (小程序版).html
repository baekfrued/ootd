✨ 3分钟拥有你的专属手机穿搭小程序

无需买服务器、无需写后端！所有自定义分类、衣服单品和压缩后的高清穿搭照片都安全保存在你手机本地的 IndexedDB 大容量数据库中。

第一步：保存代码为 index.html

将右侧编辑器的完整代码复制保存为 index.html 文件。

第二步：一键免费托管生成网址 (任选其一)
  • 方法1 (最简单)：打开 app.netlify.com/drop 或腾讯云 EdgeOne Pages，直接上传 index.html，5秒生成专属 https:// 网址。
  • 方法2 (GitHub Pages)：在手机或电脑打开 GitHub 新建仓库，上传 index.html，在 Settings -> Pages 开启即可获得永久免费网址。
第三步：在手机微信设为浮窗或添加到桌面
  • 微信内秒开：把网址发给微信“文件传输助手”，点开后点击右上角 ⋯ -> 选择「浮窗」或「收藏」。
  • 手机桌面图标 (像原生App)：用 iPhone Safari（点底部分享按钮 -> 添加到主屏幕）或安卓浏览器（点菜单 -> 添加到桌面），桌面就会生成独立图标，全屏打开！

数据备份与恢复

您创建的自定义分类、单品与穿搭照片均持久保存在手机本地 IndexedDB 中，刷新绝不丢失。换手机或清理缓存前可导出备份文件。
